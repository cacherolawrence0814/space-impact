# Space Impact

Pixel-art space shooter. 10 levels, a boss after 60 seconds of each level, 3 lives, power-ups, and a local high-score board.

## Play
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > deploy from branch, root) to host it.

## Controls
- Move: Arrow keys / WASD, or drag on touch screens
- Fire: automatic
- B: bomb, H: black hole (or tap the buttons)

## Power-ups
F fire speed, S ship speed, L laser, M machine gun, R bazooka, B bomb, H black hole.

High scores are saved in the browser (localStorage), per device.
